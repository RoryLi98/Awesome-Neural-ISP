About the library

Each publication has one primary task. Controllable and mobile/efficient ISPs are overlapping collections; model, training, signal and control tags are independent filters. Challenge implementations are attached to their reports and do not increase the publication count. Code and weight totals include explicitly labeled third-party releases.

This is a curated index, not an exhaustive survey. Journal-only work and newly released proceedings may be missing.
