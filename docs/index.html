How this list was built

Candidates came from keyword screening of CVPR, ICCV and WACV papers on CVF Open Access (2017–2026), the CVF workshops (NTIRE, Mobile AI, MIPI, AIM and others), ECCV 2018–2024 on ECVA, NeurIPS 2019–2024, reverse-chronological arXiv title searches, and related curated lists. GitHub repository search was used to find code for papers that do not link any.

For every repository the README (and, where needed, the file tree) was read on 2026-09-29, and the download links, extraction codes and hosts it gives were recorded. No checkpoint was downloaded or run; hosted files can disappear, and Google Drive enforces daily download quotas. Checkpoints remain under their authors' licenses.

Known gaps: ECCV 2026 and NeurIPS 2025 proceedings were not fully available; AAAI, ACM MM, TIP, TPAMI, IJCV and BMVC are covered through arXiv, so journal-only papers may be missing. Out of scope: general restoration backbones, sRGB-only enhancement or denoising, RAW-domain NeRF / 3DGS, and multispectral or polarization demosaicing. Found a gap? Contributions are welcome.
